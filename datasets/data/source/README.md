# Source datasets

These files were supplied by the project owner on 2026-09-17. They are raw inputs, not application defaults.

- `occupation_data.csv`, `job_titles.csv`, and `software_skills.csv`: O*NET reference data for user-initiated imports.
- `Skill_Job_Matching_Dataset.csv`, `all_job_post.csv`, and `Placement_Data_Full_Class.csv`: optional user-provided analysis inputs.
- `01_people*.csv`: contains personal contact fields. Do not publish or expose these files in the client application without the data subjects' authorization.

The application must calculate results only after the user imports data or enters it in the interface.
